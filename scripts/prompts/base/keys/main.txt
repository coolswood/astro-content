Стиль и Тон:
- Перевод должен быть профессиональным, но теплым и поддерживающим (сфера Care/Mental Health). Личный, уважительный подход.
- Текст должен звучать максимально нативно для носителя соответствующего языка.

Целевые языки (используй эти коды как ключи в результирующем JSON):
{{TARGET_LANGS}}

Задачи:
1. Перевод: Переведи значения из поля "data" предоставленного JSON на **ВСЕ** указанные выше языки. Обязательно обработай **каждый** из перечисленных целевых языков и никаких других.

Контекст принятых переводов (поле "context", если есть):
- Это уже принятые переводы ДРУГИХ ключей того же приложения на те же языки. Переводить их и включать в ответ НЕ нужно — это образец стиля, тона и терминологии: твои переводы должны звучать в одном ряду с ними.
- УНИКАЛЬНОСТЬ: если два разных ключа различаются в оригинале, их переводы обязаны различаться на каждом языке. Особенно строго для списков однотипных слов — эмоции, категории, названия: «тревога» и «тревожность», «надежда» и «безнадёжность» не могут переводиться одним словом. Проверь свои переводы на совпадения с переводами из context и между собой — при совпадении замени на синоним, различающий их.

Формат ответа:
Верни **ТОЛЬКО** JSON-объект, где:
- Ключи верхнего уровня — это **коды языков** из списка выше (например, "en", "de", "pt_BR").
- Значения — объекты с оригинальными ключами исходного JSON и переведенным текстом.
- Старайся подбирать переводы примерно соответсвующие по длине оригинальным.
- Ключи, начинающиеся с @ (например, "@key"), содержат описание и контекст для основного ключа "key". Используй их для более точного перевода, но само описание переводить не нужно. Удаляй эти информационные ключи из итогового JSON.

Пример ответа:
```json
{
  "en": {
    "greet": "Hello",
    "settings": "Settings"
  },
  "de": {
    "greet": "Hallo",
    "settings": "Einstellungen"
  }
}
```
Никаких комментариев до или после. СТРОГО только JSON.
