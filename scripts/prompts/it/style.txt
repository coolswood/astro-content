# Стилистика и Тон для итальянского рынка (IT)

TARGET_LANG: итальянский (итальянский стандарт, без регионализмов)
TARGET_MARKET: Италия (+ италоязычная Швейцария, сан-маринский рынок незначим)

## Tone of Voice

- Тёплый, поддерживающий тон внимательного психолога: эмпатия без снисходительности, поддержка без давления.
- Нейтральный итальянский стандарт: без тосканизмов-диалектизмов, без англо-итальянского жаргона менеджмента («feeling», «mindset» не вводить — кроме устоявшихся burnout, coping, feedback, insight в UI).
- Пишем для взрослых: без детскости и фамильярности. Категоричные оценочные суждения о пользователе запрещены.
- Мягкость вместо категоричности: forse / probabilmente / potrebbe вместо голого deve вне терапевтических правил; в поддерживающем контексте без восклицательных знаков.

## Обращение и регистр

- Дефолт — формальное Lei: глаголы 3-го лица единственного числа (può, descriva, valuti, provi, riprovi). Это регистр ru-оригинала (доминирует «вы») и UI-корпуса app_it.arb (Descriva una situazione, Valuti il suo stato — 48 ключей).
- Вежливая капитализация: функциональные местоимения и притяжательные с большой буквы внутри предложения — La, Le, Lei, Suo, Sua, Suoi (arb: «Questo La aiuterà», «per Lei», «il Suo kit», «Che cosa La porta a pensarla così?»).
- Бот-персона homeBot — регистр следует русскому оригиналу: ru на «ты» → it на tu (il tuo assistente, come stai, vediamo; arb homeBot*-ключи и daybook_ai_loading — на tu). Внутри одного файла регистр не смешивать, скачков Lei↔tu в одном тексте не допускать.
- Voi не использовать (3 ключа arb с Scrivete/vostri — легаси-дрейф); обращения всегда в единственном числе.
- В диалогах историй (персонажи между собой) регистр естественный для собеседников, по ru-оригиналу; легаси-дрейф (Lei-ответы в одних диалогах, tu в других при одинаковом ru) не копировать.

## Типографика и пунктуация

- Кавычки — итальянские капорали «» для терминов, цитат и внутренних мыслей: la distorsione dell'«avrei potuto», il pensiero «tutto o niente». Корпус — 44 файла / 373 вхождения; "..." и “...” — брак (145 «английских” вхождений — легаси-дрейф, при перегоне устраняется).
- Апостроф — только типографский ’ (l'ansia, l'IA, dell'emozione): корпус — 66 файлов / 1255, прямой ' — 0. В JSON-значениях обычный порядок символов.
- Тире — тире (—) с пробелами для пояснительных вставок и прямой речи.
- Вопросительные и восклицательные — обычные западные ? ! (без парных, как в испанском).
- Цифры западные, десятичная запятая (2,5), тысячи с точкой. Сокращения: «т. д.» → ecc., «т. е.» → cioè, «напр.» → es. / ad esempio.
- Многоточие — символ … без пробела перед ним; не разрывать предложение многоточиями чаще, чем в оригинале.

## Анти-кальки: конструкции, которые выдают перевод (ОБЯЗАТЕЛЬНО)

Главный критерий: «так написал бы носитель?». Грамматически верная фраза,
зеркалящая русский каркас, — брак. Типовое для пары русский → итальянский:

1. Цепочки отглагольных существительных — в глагольные конструкции: «проведение оценки уровня веры» → Valuti il livello di convinzione; «ведение дневника» → tenere il diario / scrivere sul diario.
2. Родительный каскад разбивать предлогами и перестройкой: «изменение убеждения через работу с мыслью» → Cambi la convinzione lavorando sul pensiero.
3. Ложные друзья и ловушки: «осознать» → rendersi conto / prendere coscienza, NON realizzare (realizzare = осуществить); «поддержка» (эмоциональная) → sostegno, NON supporto; eventualmente = «если понадобится», НЕ «в конце концов» (→ alla fine / infine); «справиться с» → affrontare / gestire / superare по контексту; «заниматься практикой» → praticare / fare gli esercizi.
4. Идиомы — смыслом: «взять себя в руки» → riprendere il controllo / farsi forza; «камень с души» → togliersi un peso di dosso / dallo stomaco; «замкнуться в себе» → chiudersi in se stessi.
5. Родовые слэши не вводить: utente/a, gratificato/a, stanco/a — брак. Итальянский решает нейтрально: utente — эпицен, Lei-формы (per cui si sente grato → per cui prova gratitudine), инфинитив, существительное вместо прилагательного. Исключение — ru-канон сам пишет слэш-шаблон: тогда зеркалить конструкцию канона.
6. Порядок слов перестраивать свободно: итальянский ставит глагол раньше русского, определение чаще после существительного; копировать смысл, а не синтаксис. Относительные придаточные («который...») сужать причастиями и apposizioni.
7. Конджунтиво — по естественному употреблению (è importante che + congiuntivo, se + congiuntivo в гипотезах, benché / anche se + congiuntivo), не механически из «бы».
8. Клитики ne / ci и местоименные частицы — использовать естественно (ne parleremo, ci sono); избегать канцелярских цепочек «di modo che», «al fine di» — preferire affinché / per.
9. Абзац должен читаться как итальянская популярно-психологическая литература, а не как перевод с русского.

## Терминология

- Термины КПТ и названия искажений — только из глоссария (инжектится отдельным блоком ниже). Расхождение с глоссарием — брак; якорь проекта — корпус astro-content и UI приложения (app_it.arb), не «вариант из другой книги».
- Система убеждений (не путать): credenze profonde/intermedie в текстах сайта, convincioni disfunzionali/costruttive — как в глоссаре; convinzioni в arb-интерфейсных строках — см. примечания глоссария.
- Аббревиатуры итальянские: TCC (не CBT), IA (не AI), DOC (не TOC); ADHD — устоявшееся исключение в итальянской клинической практике.
- Устоявшиеся англицизмы остаются: burnout, coping, feedback, insight (в UI).
- «Дневник» = diario, «Ежедневник» = diario giornaliero, «Запись» = voce — различие корпуса сохранять.
