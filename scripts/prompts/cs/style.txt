# Стилистика и Тон для чешского рынка (CS)

TARGET_LANG: чешский (CS, spisovná čeština — литературный чешский)
TARGET_MARKET: Чешская Республика

## Tone of Voice

- Тёплый, поддерживающий тон внимательного психолога: эмпатия без снисходительности, поддержка без давления.
- Только литературный чешский (spisovná čeština). Разговорные/диалектные формы (obecná čeština: -ej, vo-, von, bejt) — брак; псевдо-книжный канцелярит (z důvodu, ve smyslu, provedení) — тоже.
- Пишем для взрослых: без детскости и фамильярности. Категоричные оценочные суждения о пользователе запрещены.

## Обращение и регистр

- Дефолт корпуса — формальное «вы»: vy, váš, vám со строчной буквы («váš stav se zlepšil», «Bylo by pro vás pohodlné...»); императив мн.ч.: Zapište, Vyzkoušejte, Vyplňte.
- Регистр следует русскому оригиналу: где оригинал на «ты» (бот-контент homeBot), чешский — на ty (ty jsi, tvůj, máš); внутри одного файла регистр не смешивать.
- Заглавное Vy/Váš (переписная вежливость) не вводить — корпус везде со строчной.

## Типографика и пунктуация

- Кавычки — чешские нижние „“ (780 вхождений корпуса) для терминов, цитат и выделений: zkreslení „mělo by“. Не «ёлочки» и не "..."/“...” (случайные « в корпусе — дрейф, не копировать).
- Тире — длинное — с пробелами (корпус: 567 вхождений « — »), для пояснительных вставок и прямой речи.
- Цифры западные, десятичная запятая. Сокращения: «т. д.» → atd., «т. е.» → tj., «напр.» → např.

## Анти-кальки: конструкции, которые выдают перевод (ОБЯЗАТЕЛЬНО)

Главный критерий: «так написал бы носитель?». Грамматически верная фраза,
зеркалящая русский каркас, — брак. Типовое для пары русский → чешский:

1. Цепочки отглагольных существительных — в глагольные конструкции: «проведение оценки уровня веры» → Ohodnoťte, jak moc věříte přesvědčení; «ведение дневника» → vést deník / zapisovat si.
2. Родительный каскад существительных разбивать: «изменение убеждения через работу с мыслью» → Změňte přesvědčení tak, že budete pracovat s myšlenkou.
3. Клитики (se, si, vám, tě, ho, mi) — на вторую позицию фразы, не зеркалить русский порядок слов: «Позвольте себе расслабиться» → Dovolte si uvolnit (не Dovolte uvolnit si). Порядок слов перестраивай свободно: копируй смысл, а не синтаксис.
4. Ложные друзья: «правильный» → správný (pravý = правый/истинный), «аккуратно» → pečlivě (opatrně = осторожно), «осторожный» → opatrný, «урок» → lekce (úrok = процент), «неделя» → týden (neděle = воскресенье), «запах» → vůně/pach по валентности (zápach = зловоние), «образ жизни» → životní styl, «строгий» → přísný (strohý = суровый/резкий).
5. «Заниматься практикой» → věnovat se praxi / cvičit / praktikovat по контексту; zabývat se — только про «заниматься вопросом».
6. Идиомы — смыслом: «взять себя в руки» → sebrat se / vzít se dohromady, «камень с души» → mi spadl kámen ze srdce (жить в чешском, не калькировать редко).
7. Мягкость вместо категоричности: pravděpodobně / zřejmě / může вместо голого musíte вне терапевтических правил; в поддерживающем контексте без восклицательных знаков.
8. Родовые слэши не вводить: zvládl/a, dobrý/dobrá, uživatel/ka — брак. Русский канон никогда не пишет «справлялся/справлялась»; где оригинал в мужском роде или нейтрален — мужской как генерический, либо перестройка во 2-е лицо настоящего времени (zvládnete).
9. Абзац должен читаться как чешская книга по самопомощи (česká populárně-psychologická literatura), а не как перевод с русского.

## Терминология

- Термины КПТ и названия искажений — только из глоссария (инжектится отдельным блоком ниже). Расхождение с глоссарием — брак; якорь проекта — корпус astro-content и UI приложения (app_cs.arb), а не «вариант из другой книги».
- «Ежедневник» и «Дневник» по-чешски слились в deník — не изобретать diář/plánovač. AI не раскрывается (стандартное чешское сокращение): Doporučení od AI, analýza od AI; в нарративе при первом упоминании — umělá inteligence.
