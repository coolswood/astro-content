# Стилистика и Тон для испанского рынка (ES)

TARGET_LANG: испанский (ES, нейтральный международный испанский, без регионализмов)
TARGET_MARKET: Испания + Латинская Америка

## Tone of Voice

- Тёплый, поддерживающий тон внимательного психолога: эмпатия без снисходительности, поддержка без давления.
- Нейтральный испанский (es internacional): без испанизмов-регионализмов (ordenador, coche, vale) и без латинскоамериканских локализмов; устройство — el dispositivo / la aplicación, не computadora/ordenador.
- Пишем для взрослых: без детскости и фамильярности. Категоричные оценочные суждения о пользователе запрещены.
- Мягкость вместо категоричности: probablemente / posiblemente / puede que вместо голого tiene que вне терапевтических правил; в поддерживающем контексте без восклицательных знаков.

## Обращение и регистр

- Дефолт — формальное usted: глаголы 3-го лица единственного числа (puede, describa, revise, anote, intente). Это регистр ru-оригинала (доминирует «вы») и UI-корпуса app_es.arb (Revise sus registros, Anote...).
- Регистр следует русскому оригиналу: бот-контент homeBot в ru на «ты» → es на tú (tu asistente, acompañarte, recuerda); внутри одного файла регистр не смешивать, скачков usted↔tú в одном тексте не допускать.
- Бонус usted-форм: гендерно нейтральны (puede, se siente) — предпочитать их там, где иначе выпал бы род.
- vosotros не использовать (LatAm его не знает); обращения всегда в единственном числе.

## Типографика и пунктуация

- Кавычки — испанские латинские «» (comillas angulares) для терминов, цитат и внутренних мыслей: la distorsión de los «debería», «Si tan solo...». Корпус (distortions.json, story) — только «»; не "..."/“...”.
- Тире — raya (—) с пробелами для пояснительных вставок и прямой речи.
- Вопросительные и восклицательные — с парными ¿? ¡! (в UI-жанре; в нарративах умеренно, без ¡...! в терапевтических фрагментах).
- Цифры западные, десятичная запятая (корпус тестов: 2,5; 2,8). Сокращения: «т. д.» → etc., «т. е.» → es decir, «напр.» → p. ej.
- Многоточие — три точки без пробела перед ними; не разрывать предложение многоточиями чаще, чем в оригинале.

## Анти-кальки: конструкции, которые выдают перевод (ОБЯЗАТЕЛЬНО)

Главный критерий: «так написал бы носитель?». Грамматически верная фраза,
зеркалящая русский каркас, — брак. Типовое для пары русский → испанский:

1. Цепочки отглагольных существительных — в глагольные конструкции: «проведение оценки уровня веры» → Evalúe el nivel de creencia; «ведение дневника» → llevar el diario / escribir en el diario.
2. Родительный каскад разбивать: «изменение убеждения через работу с мыслью» → Cambie la creencia trabajando con el pensamiento.
3. Ложные друзья и англицизмы: soporte → apoyo; asumir = «брать на себя», «предполагать» → suponer; «осознать» → tomar conciencia / darse cuenta, не realizar; eventually → finalmente, не eventualmente; focalizar → centrarse / prestar atención; «конкретно» → concretamente.
4. «Справиться с» → hacer frente a / afrontar / superar по контексту; «заниматься практикой» → practicar / hacer los ejercicios.
5. Идиомы — смыслом: «взять себя в руки» → reaccionar / controlar la situación; «камень с души» → quitarse un peso de encima.
6. Родовые слэши не вводить: usuario/a, agradecido/a, todos/as — брак. Где род виден — мужской как генерический, либо перестройка: usted-форма («por lo que sienta gratitud» вместо «agradecido/a»), инфинитив, существительное вместо прилагательного. Исключение — ru-канон сам пишет слэш-шаблон: тогда зеркалить конструкцию канона.
7. Порядок слов перестраивать свободно: испанский ставит глагол раньше русского, определение чаще после существительного; копировать смысл, а не синтаксис. Относительные придатные («который...») сужать причастиями и предикативами.
8. Сослагательное наклонение — по естественному употреблению (es importante que + subjuntivo, cuando + subjuntivo для будущих ситуаций), не механически из «бы».
9. Абзац должен читаться как испанская популярно-психологическая литература, а не как перевод с русского.

## Терминология

- Термины КПТ и названия искажений — только из глоссария (инжектится отдельным блоком ниже). Расхождение с глоссарием — брак; якорь проекта — корпус astro-content и UI приложения (app_es.arb), не «вариант из другой книги».
- Устоявшиеся англицизмы испанского остаются: burnout (не agotamiento как термин), insight (в UI), IA (аббревиатура стандартна, не раскрывается в коротких строках; в нарративе при первом упоминании — inteligencia artificial).
- «Дневник» = diario, «Ежедневник» = agenda (diaria/inteligente) — различие корпуса сохранять в текстах сайта; в интерфейсных строках править по arb.
