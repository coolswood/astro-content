# Постановка: отказ от lingo.dev, приведение в порядок собственной системы локализации

> Бриф для отдельной сессии. Репозиторий: `/Users/daniel/Desktop/projects/astro-content`.

## Контекст

Проект — бэкенд контента для Flutter-приложения cognitive_psy (сиблинг `../cognitive_psy`). Локализация двухуровневая:

- **Контент**: `src/i18n/ru` → `src/i18n/<lang>` — 19 локалей (ar cs de en es fr he id it ja ko nl pl pt pt_br ru sv tr uk), ~66 JSON-файлов на локаль, раздаётся по HTTP (Vercel).
- **UI Flutter**: канон `app_ru.arb` в cognitive_psy; переводы пишутся из этого репо скриптом `scripts/translate-arb.ts`.

Проведённый эксперимент (lingo.dev + локальная модель) дал два вывода:

1. **Качество даёт наш трёхстадийный конвейер** (main → editor → tech), собранный из `scripts/prompts/`: `base/text/{main,editor,tech}.txt`, `base/fragments/*`, `<lang>/style.txt`, `<lang>/glossary.json`. Локальная модель + наш конвейер = паритет с прежними облачными прогонами (проверено слепым MQM-сравнением; судья — та же модель, учитывать её позиционное смещение: сигналом считать только стабильные 2:0).
2. **lingo.dev был только обвязкой** (скан файлов, lockfile, запись JSON), потребовал двух патчей в бандле. Решено: убрать, своё — в порядок.

### Инфраструктура модели

- **SSH**: `ssh -i "/Users/daniel/Library/Application Support/NVIDIA/Sync/config/nvsync.key" coolswood@192.168.31.18` (в `~/.ssh/config` из NVIDIA Sync — хост `server`/`server-local`).

- **Прокси** `scripts/lingo_proxy.py` (порт 18001): OpenAI-совместимый, рендерит наши промпты, гоняет 3 стадии, содержит глобальный лок «один запрос к модели единовременно».
- **⚠️ Жёсткое правило: к модели — строго 1 одновременный запрос.** gx10 перегружается от параллельных (уже обжигались).

## Цель

Полностью убрать lingo.dev и собрать собственный поддерживаемый раннер перевода поверх существующих активов (промпты, глоссарии, прокси/vLLM), починив известные болезни текущих скриптов.

## Задачи

1. **Демонтаж lingo.dev**: devDependency `lingo.dev` из `package.json`, каталог `patches/` + `patchedDependencies`, файлы `i18n.json`, `i18n.lock`.
2. **Единый раннер** (bun/TS) вместо зоопарка `translate-arb.ts` / `translate-ui.ts` / `translate-file*.ts`:
   - источник истины по промптам — `scripts/prompts/`, ничего не дублировать;
   - провайдер — HTTP к vLLM/прокси; Puppeteer-провайдеры (ChatGPT/Claude/Gemini через CDP :9222) вывести за общий интерфейс провайдеров, пометить legacy, не удалять сразу;
   - стадии main → editor → tech — переиспользовать логику `scripts/lingo_proxy.py` (встроить в раннер или оставить прокси отдельным сервисом — по критерию «минимум движущихся частей»);
   - **инкрементальность**: per-key хэши ru-значений в закоммиченном state-файле; первый прогон инициализирует state из существующих переводов (лечим мёртвые зоны старого `ru_snapshot.json`, куда не попали ключи до его создания);
   - JSON: поддержать и объекты, и массивы строк (в контенте есть массивы, напр. `texts/psychologist.json`);
   - **валидация**: полное совпадение ключей, сохранность плейсхолдеров `{…}` и тегов (`<b>`, `<q>`, `<important>`, `<instagram>`), детект «чужих» алфавитов (есть в `check-translations.ts` / SCRIPT_MAP), авторетрай при битом JSON (при необходимости `response_format: json_object`);
   - сохранить `--dry-run` и resume/кэш (порт логики из `translate-arb.ts`);
   - конфигурация: список локалей, путь до cognitive_psy (снять хардкод `../cognitive_psy` → env/конфиг), endpoint и имя модели.
3. **Глоссарии для 13 локалей без них** (ar cs en es fr he id it ko nl pt sv uk): извлечь термины КПТ из старых проверенных переводов и разложить в `scripts/prompts/<lang>/glossary.json` по образцу `scripts/prompts/ja/glossary.json`. Проверенный факт: без глоссария модель калькирует «глубинные убеждения» вместо принятых терминов.
4. **Чистка легаси**: `scripts/app_interface.json` — add-only зеркало; удалить вместе с потребителем или заменить честной синхронизацией (решить по факту осмотра). `scripts/AI_INSTRUCTIONS.md` устарел (ссылается на переименованные скрипты) — переписать. README привести в порядок.
5. **Тесты** на state/дифф/валидацию (bun test / vitest); опционально CI-джоба с dry-run.
6. **Миграция состояния**: в рабочем дереве лежат свежие переводы `story/start.json` ×18, сделанные новым конвейером (незакоммичены). Бэкапы: `/tmp/start-backup/` (старый конвейер), `/tmp/start-new-v1/` (однокопроходный) — **/tmp эфемерен, до начала работ перенести нужное в репо или закоммитить текущее состояние**.

## Ограничения

- **Не менять содержание `scripts/prompts/**`** — это выверенный актив качества; менять можно только код, который его потребляет.
- К модели — строго 1 одновременный запрос (глобальный лок/очередь), независимо от параллелизма раннера.
- cognitive_psy в этой задаче не рефакторим; его merge-валидатор требует отсутствия лишних ключей в `app_<lang>.arb` — purge dead keys обязан сохраниться.
- Бесплатно: никаких платных API.

## Критерии приёмки

- `--dry-run` даёт корректный отчёт missing/changed/dead по всем 19 локалям; детект изменений без мёртвых зон (проверить внесением правки в ru-ключ и убедиться, что он поймался).
- Полный прогон `story/start.json` на 18 локалей: валидация 100% (ключи/плейсхолдеры/теги/алфавиты), качество не ниже текущего v2 (выборочное слепое A/B-сравнение по MQM-методике из этой сессии).
- lingo.dev отсутствует в зависимостях и репозитории; `bun install` чистый.
- Прогон — одной командой при поднятом туннеле; при недоступности модели — понятная ошибка без частичной записи файлов.
