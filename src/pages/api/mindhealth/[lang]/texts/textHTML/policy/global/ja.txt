<h2>本サービスの原則：閉じた処理ループ</h2>
<p>本サービスは、私ども独自の閉じたループとして構築されています。皆様のノート、会話、音声は、欧州連合（EU）内の私ども独自のインフラストラクチャ上で稼働する、私ども独自のサーバーと私ども独自のAI（人工知能）・音声認識モデルによって処理されます。</p>
<p>私どもは、個人データを販売せず、広告主やデータブローカーへ渡すことなく、広告ネットワークを利用することも、皆様のデータに基づく広告を表示することもありません。</p>
<p>例外的な場合、すなわち私ども独自の処理能力が利用できない場合、または特定のご要請が私どもの手段では技術的に実現できない場合（たとえば、非常に長い音声録音など）には、そのご要請を処理するために外部の技術サービスを利用することがあります。データは、当該のご要請の遂行にのみ使用されます。</p>

<h2>処理されるデータ</h2>
<p>本サービスは、アプリのユーザー向けのものです。ご利用になる機能に応じて、以下のデータが処理されます。</p>
<ul>
<li>アカウントデータ：メールアドレス、端末およびアプリインストールの識別子</li>
<li>サービスの初期設定時にご入力いただく情報：お名前、性別、年齢、目標およびご要請</li>
<li>本サービスのご利用の内容：日記の記録（テキストおよび写真）、気分の記録、エクササイズとテストの結果、AIアシスタントとの会話</li>
<li>音声認識のために録音される音声データ</li>
<li>サポートへのお問い合わせ</li>
<li>技術データ：IPアドレス、セッションおよびエラーログの詳細、プッシュ通知トークン</li>
<li>お支払い情報：サブスクリプションのステータスと金額、支払い履歴</li>
</ul>
<p>クレジットカード情報はアプリストアによって処理されており、本サービスへ送信されることは一切ありません。</p>

<h2>ログイン</h2>
<p>ログインは、メールアドレスに送信されるワンタイムコード、またはGoogle、Apple、Yandexの各アカウントを通じて行われます。後者の場合、私どもはそのアカウントからお名前とメールアドレスを受け取ります。Googleから受け取ったデータは、Google APIサービスの限定利用要件（Google API Services Limited Use）に従って使用されます。</p>

<h2>処理の目的と法的根拠</h2>
<ul>
<li>サービスの運営（皆様のアカウント、ノートの端末間同期、AIアシスタントおよび音声認識）：ユーザー契約の履行（GDPR 第6条(1)(b)）</li>
<li>心理的・情緒的な状態に関するデータ（日記の記録、気分の記録、AIアシスタントとの会話）：特別なカテゴリーに属するデータ（GDPR 第9条）。これらは、対象となる機能をご利用になることで皆様が与えられる同意に基づいて処理され、同意はいつでも撤回していただけます</li>
<li>お支払いの受付およびサブスクリプションの管理：契約の履行（第6条(1)(b)）</li>
<li>ログインコードおよびプッシュ通知の送信：契約の履行（第6条(1)(b)）</li>
<li>利用統計ならびに本サービスの安定性および安全性の確保：管理者の正当な利益（第6条(1)(f)）。このような処理については、異議を申し立てることができます（第21条）</li>
<li>法的義務の遵守：法律（第6条(1)(c)）</li>
</ul>

<h2>自動化された処理</h2>
<p>AIアシスタントは皆様のノートとご要請に基づいて回答を作成し、音声認識は音声をテキストに変換します。これらの機能は皆様がご要請された内容を実行するものであり、皆様に関する法的な効果を生じさせる決定が自動的に下されることはありません。</p>

<h2>データの保存場所と保存期間</h2>
<p>データは、EU内に設置された私ども独自のサーバーに保存されます。同期が有効になっている場合、データはサーバーと同期されます。同期を無効にすると、ノートはお使いの端末内にのみ残ります。</p>
<p>法律により別の期間が定められていない限り、データは皆様が本サービスをご利用している間処理されます。アカウントを削除すると、日記の記録、ノートおよび皆様が作成されたデータは削除されます。一部の記録、すなわちお支払い記録、技術ログおよびサポート対応の記録は、法律で定められた期間、または本サービスの運営に必要な期間保管されることがあります。このようなデータの削除は、管理者の窓口にご請求いただけます。</p>

<h2>データにアクセスできるその他の主体</h2>
<p>私ども以外でデータへの限定的なアクセスを持つのは、本サービスの稼働を支える以下の主体のみです。</p>
<ul>
<li>アプリストア（Apple App Store、Google Play）：お支払い処理に必要な範囲内で</li>
<li>メール配信サービス：ログインコードを配信するため</li>
<li>プッシュ通知サービス（Google、Apple）：通知を配信するため</li>
<li>プロダクト分析サービス（EU内または私ども独自のサーバー上で稼働）：技術データ（IPアドレス、セッションの情報）</li>
<li>ホスティングプロバイダ：私どものサーバーを設置し保護するため（EU）</li>
</ul>
<p>これらの主体がデータをその他の目的に使用することは認められていません。データが販売されることは、いかなる場合にもありません。</p>
